# TrainerLink

TrainerLink is a personal trainer Android app. It is designed to save time and give trainers and clients a way to stay connected, in and out of the gym. It is an application for mobile phones.

## Who it is for

* Personal trainers who work with clients
* Clients who maintain contact with their trainer via their cell phone

## Language

It will be developed in Android Studio with Java.

## Planned features

Accounts

* Trainer or client role selected when signing up
* Login with Firebase Authentication
* Clients are invited by email or code by a trainer, thus each client is connected to a trainer

Trainer features

* List of clients including a quick status indicator for each client
* Create workout plans: exercises, sets, reps and notes
* Assign a workout to a client on a designated day
* Reusable workout templates
* Client progress view with completed workouts over time
* Messaging with each client

Client features

* Today's workout screen
* Mark exercises as finished and record weight and reps
* Progress history
* Messaging with the trainer

Other features

* New workouts and messages will be sent as push notifications

## Data

Firebase in the cloud keeps trainer and client data in sync in real time. An SQLite database on the phone will serve as a cache and the app will continue to function without an Internet connection.
